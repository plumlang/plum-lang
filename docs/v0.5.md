# 🍑 Plum v0.5 — Comments

## Release Date

September 2026

## Overview

Version 0.5 introduces comments to Plum using a simple double-dash syntax.

## Plum Language Changes

### Comment Syntax

Plum uses `--` to start and end a comment.

```plum
-- This is a comment --
```

Comments can also appear after a statement:

```plum
drop 10 + 5 -- This is an inline comment --
```

### Lexer

The lexer should recognize `--` as the beginning of a comment and ignore all characters until the next `--`.

Comment content should not produce tokens.

Example:

```plum
-- hello --
drop 10 + 5
```

should tokenize only the `drop 10 + 5` statement.

### Important

`--` uses the same character as the subtraction operator, so the lexer must distinguish:

```plum
drop 10 - 5
```

from:

```plum
-- comment --
```

A single `-` remains the subtraction operator.

## VS Code Extension Changes

The separate `plum-vscode` repository should also support the new comment syntax.

### Syntax Highlighting

Update:

`syntaxes/plum.tmLanguage.json`

The comment rule should recognize:

```plum
-- comment --
```

using the comment scope:

```json
"comments": {
  "name": "comment.line.double-dash.plum",
  "begin": "--",
  "end": "--"
}
```

### Boolean Highlighting

The VS Code grammar should recognize Plum's boolean values:

```plum
good
bad
```

as language constants.

```json
"constants": {
  "name": "constant.language.plum",
  "match": "\\b(good|bad|null|undefined)\\b"
}
```

### Existing Operators

The syntax highlighting should continue supporting:

```text
+  -  *  /  %  //  **
==  !=  <  >  <=  >=
```

`**` and `//` should be matched before `*` and `/`.

## Testing

Test comments with:

```plum
-- full line comment --

drop 10 + 5

drop 20 - 5 -- inline comment --

-- another comment --
```

Also test:

```plum
-- comment --
drop 10
-- another comment -- drop 20
```

Make sure subtraction still works:

```plum
drop 10 - 5
```

## Expected Result

Comments should:

- Be ignored by the Plum lexer
- Not reach the parser or interpreter
- Work on their own line
- Work after a Plum statement
- Use `--` as both opening and closing delimiters
- Be highlighted as comments in VS Code

## v0.5 Goal

Add clean and simple comment support to Plum while keeping the existing arithmetic, comparison, and boolean functionality working.

## Current Limitations

- No variables
- No logical operators
- No conditionals
- No loops
- No functions
