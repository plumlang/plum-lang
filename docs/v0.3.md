# Plum v0.3 - Full Arithmetic Support

## Release Date: September 2026

## Overview
Version 0.3 expands Plum's arithmetic capabilities with **complete operator support**. This version adds subtraction (`-`), multiplication (`*`), and division (`/`), along with parentheses for grouping expressions.

## New Features

### 1. New Operators

| Operator | Description | Example | Result |
|----------|-------------|---------|--------|
| `+` | Addition | `5 + 3` | `8.0` |
| `-` | Subtraction | `10 - 4` | `6.0` |
| `*` | Multiplication | `6 * 7` | `42.0` |
| `/` | Division | `20 / 5` | `4.0` |

### 2. Operator Precedence
Proper mathematical precedence is now enforced:

| Precedence | Operators | Associativity |
|------------|-----------|---------------|
| Highest | `*`, `/` | Left-to-right |
| Lowest | `+`, `-` | Left-to-right |

**Examples:**
```plum
drop 10 + 5 * 2     # 20.0 (not 30.0)
drop (10 + 5) * 2   # 30.0
drop 20 / 4 + 3     # 8.0
drop 5 * 5 - 3      # 22.0
