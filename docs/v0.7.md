# Plum v0.7 - Functions & Scope

## Release Date: September 2026

## Overview
Version 0.7 introduces **functions** and **lexical scoping** to Plum. This version adds the ability to define reusable functions with type-safe parameters and return values, along with proper variable scoping that allows local variables inside functions.

## New Features

### 1. Function Declaration (`branch`)

Functions are declared using the `branch` keyword, followed by the return type, function name, and parameters.

**Syntax:**
branch <return_type> <function_name>(<parameter_type> <parameter_name>, ...) {
<statements>
}


**Example:**
```tsx
branch int add(int a, int b) {
    return a + b
}

branch void sayHello(str name) {
    drop "Hello, " + name
}
```
### 2. Return Types

Functions can return values using the `return` statement. The return type must match the declared type.

| Return Type | Description | Example |
|---|---|---|
| `int` | Returns an integer | `return 42` |
| `str` | Returns a string | `return "Hello"` |
| `bool` | Returns a boolean | `return true` |
| `float` | Returns a float | `return 3.14` |
| `void` | Returns nothing | `return` (optional) |
- Examples:

```tsx
branch int getAge() {
    return 25
}

branch str getName() {
    return "Subhro"
}

branch bool isActive() {
    return true
}

branch void logMessage(str msg) {
    drop "LOG: " + msg
    # No return statement needed for void
}
```

### 3. Function Parameters
Functions can accept multiple parameters with explicit types:
```tsx

branch int multiply(int a, int b, int c) {
    return a * b * c
}

branch str greet(str firstName, str lastName) {
    return "Hello, " + firstName + " " + lastName
}

```


### 4. Function Calls
Functions are called using their name followed by parentheses with arguments:

```tsx
plant int result = add(5, 3)
drop result                    # 8

drop multiply(2, 3, 4)        # 24

drop greet("Subhro", "Roy")   # Hello, Subhro Roy
```


### 5. Local Scope
Variables declared inside a function are local to that function:
```tsx
branch int calculate(int x, int y) {
    plant int temp = x + y    # Local variable
    plant int result = temp * 2  # Local variable
    return result
}

# temp and result are NOT accessible here
# drop temp  # ❌ Error: Undefined variable
```

### 6. Global Variables in Functions
Functions can access global variables:

```tsx
root int MAX = 100

branch void showMax() {
    drop MAX    # ✅ Access global constant
}

showMax()       # 100
```
### 7. Nested Function Calls
Functions can call other functions:

```tsx
branch int add(int a, int b) {
    return a + b
}

branch int multiply(int a, int b) {
    return a * b
}

branch int complex(int x, int y) {
    return add(multiply(x, 2), y)
}

drop complex(5, 3)  # (5 * 2) + 3 = 13
```

### 8. Type Safety in Functions
Type errors are caught at runtime:

```tsx

# ✅ Correct
branch int add(int a, int b) {
    return a + b
}

# ❌ Type error - returning wrong type
branch int invalidFunction(str x) {
    return x  # ❌ Error: Expected int, got str
}

# ❌ Type error - wrong argument type
drop add("hello", 5)  # ❌ Error: Expected int for parameter 'a', got str
```
## Complete Syntax
Function Grammar

```text
function_declaration  → "branch" return_type IDENTIFIER "(" parameters ")" "{" statement* "}"
return_type          → "int" | "str" | "bool" | "float" | "void"
parameters           → (parameter ("," parameter)*)?
parameter            → type IDENTIFIER
return_statement     → "return" expression? ";"
function_call        → IDENTIFIER "(" arguments ")"
arguments            → (expression ("," expression)*)?
```

## Examples
```tsx
# Simple function
branch int square(int x) {
    return x * x
}

# Multiple parameters
branch int addThree(int a, int b, int c) {
    return a + b + c
}

# Void function
branch void printMessage(str msg) {
    drop "Message: " + msg
}

# Function with local variables
branch int complexCalc(int x, int y) {
    plant int temp = x + y
    plant int result = temp * 2
    return result - x
}

# Function calling other functions
branch int calculateSum(int a, int b) {
    return add(a, b)  # Calls the add function
}
```
