# Plum v0.2 - Parser & Interpreter (Basic)

## Release Date: September 2026

## Overview
Version 0.2 introduces the foundation of Plum's execution model with a **Parser** and **Interpreter**. This version adds support for basic arithmetic with the addition operator (`+`), string literals, and the `drop` statement for output.

## New Features

### 1. Abstract Syntax Tree (AST)
The AST represents the structure of Plum programs as a tree of nodes:

| Node Type | Purpose |
|-----------|---------|
| `Program` | Root node containing all statements |
| `PrintStatement` | Represents `drop <expression>` |
| `StringLiteral` | String values like `"Hello"` |
| `NumberLiteral` | Numeric values like `42` or `3.14` |
| `BinaryOperation` | Operations like `5 + 3` |

### 2. Parser
- **Recursive Descent Parser** - Handles expressions and statements
- **Precedence Climbing** - Supports proper operator precedence
- **Error Handling** - Syntax errors with line numbers
- **AST Generation** - Converts tokens into AST nodes

### 3. Interpreter
- **Tree-Walking Interpreter** - Evaluates AST nodes
- **Print Support** - `drop` statement prints values
- **String Support** - Can print string literals
- **Addition Support** - Evaluates `+` operator
- **Number Support** - Handles integers and decimals

## Supported Operations (v0.2)

### Expressions
```plum
drop "Hello, World!"    # String literal
