# Plum v0.6 - Variables & Type Safety

## Release Date: September 2026

## Overview
Version 0.6 introduces **variables** and **type safety** to Plum. This version adds support for both mutable and immutable variables with explicit type declarations, making Plum a statically-typed language.

## Core Concepts

### 1. Mutability in Plum

Plum has two types of variables based on whether they can be changed after creation:

| Keyword | Mutability | Description | Analogy |
|---------|-----------|-------------|---------|
| `plant` | **Mutable** | Can be reassigned after initialization | Like a whiteboard - you can erase and write new values |
| `root` | **Immutable** | Cannot be reassigned after initialization | Like a carved stone - once set, it cannot be changed |

### 2. Mutable Variables (`plant`)

Variables declared with `plant` are **mutable** - they can be reassigned new values after initialization.

```plum
drop "=== Mutable Variables (plant) ==="

# Declare and initialize
plant int age = 21
drop age          # 21

# Reassign - this is allowed
age = 25
drop age          # 25

# Reassign using expressions
age = age + 5
drop age          # 30

# Reassign with different values
age = 100
drop age          # 100
