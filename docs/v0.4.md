# Plum v0.4 — Extended Operators & Booleans

## Release Date

September 2026

## Overview

Version 0.4 expands Plum with extended arithmetic operators, comparison operators, and boolean values.

## New Features

### Extended Arithmetic

- `%` — Modulo
- `//` — Floor Division
- `**` — Power

### Comparison Operators

- `==` — Equal
- `!=` — Not Equal
- `>` — Greater Than
- `<` — Less Than
- `>=` — Greater Than or Equal
- `<=` — Less Than or Equal

### Boolean Values

- `good` → `good`
- `bad` → `bad`

Example:

    drop good
    drop bad
    drop 10 > 5

## Operator Precedence

    ()
    **
    * / % //
    + -
    > < >= <= == !=

Parentheses can override precedence.

Example:

    drop (2 + 3) * 4

## Implementation

- Added lexer support for extended operators and boolean keywords
- Extended recursive descent parser
- Added `BooleanLiteral` AST node
- Added interpreter support for comparisons and booleans
- Added `good` / `bad` boolean output
- Added division-by-zero protection for `/`, `%`, and `//`

## Example

    drop 5 + 3
    drop 10 % 3
    drop 2 ** 3
    drop 10 > 5
    drop 10 == 10
    drop good
    drop bad
    drop (2 + 3) * 4

## Limitations

- No variables
- No logical operators
- No conditionals
- No loops
- No functions
