# Plum v0.9 — For Loops & While Loops

## Added

Plum now supports `for` loops.

The `for` loop allows code to be repeated while a condition remains true.

---

## Syntax

```plum
for (initializer; condition; increment) {
    // loop body
}
```

Example:

```plum
for (plant int i = 1; i <= 5; i++) {
    drop (i)
}
```

Output:

```text
1
2
3
4
5
```

---

## For Loop Components

A `for` loop contains three parts:

### 1. Initializer

The initializer creates and initializes the loop variable.

```plum
plant int i = 1
```

### 2. Condition

The condition determines whether the loop should continue.

```plum
i <= 5
```

The loop continues while the condition is true.

### 3. Increment

The increment increases the loop variable after every iteration.

```plum
i++
```

The interpreter evaluates this as:

```text
i = i + 1
```

---

## Example

```plum
for (plant int i = 1; i <= 5; i++) {
    drop (i)
}
```

Execution:

```text
i = 1
→ condition: 1 <= 5
→ drop (1)
→ i++

i = 2
→ condition: 2 <= 5
→ drop (2)
→ i++

i = 3
→ condition: 3 <= 5
→ drop (3)
→ i++

i = 4
→ condition: 4 <= 5
→ drop (4)
→ i++

i = 5
→ condition: 5 <= 5
→ drop (5)
→ i++

i = 6
→ condition: 6 <= 5
→ stop
```

---

## Loop with Conditionals

`for` loops can contain existing conditional statements.

```plum
for (plant int i = 1; i <= 3; i++) {
    if (i == 2) {
        drop ("MIDDLE")
    }
}
```

Output:

```text
MIDDLE
```

---

## Loop with if-else

```plum
for (plant int i = 1; i <= 3; i++) {
    if (i == 2) {
        drop ("TWO")
    } else {
        drop ("OTHER")
    }
}
```

Output:

```text
OTHER
TWO
OTHER
```

---

## Nested For Loops

For loops can be nested inside other for loops.

```plum
for (plant int i = 1; i <= 2; i++) {
    for (plant int j = 1; j <= 2; j++) {
        drop (j)
    }
}
```

Output:

```text
1
2
1
2
```

## Implementation

### Lexer

Added tokens:

- `FOR`
- `INCREAMENT`

The lexer recognizes:

```text
for
++
```

---

### AST

Added:

```text
ForStatement
```

The `ForStatement` contains:

```text
initializer
condition
increment
body
```

---

### Parser

The parser recognizes the structure:

```text
for
 ↓
(
 ↓
initializer
 ↓
;
 ↓
condition
 ↓
;
 ↓
increment
 ↓
)
 ↓
{
 ↓
body
 ↓
}
```

---

### Interpreter

The interpreter executes the loop in the following order:

```text
1. Execute initializer
2. Evaluate condition
3. If condition is false → stop
4. Execute loop body
5. Execute increment
6. Repeat from step 2
```
