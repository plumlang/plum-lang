# Plum v0.9 — Logical Operators

## Added

Plum now supports logical operators:

- `and`
- `or`
- `not`

## Examples

### AND

```plum
if (true and true) {
    drop "both are true"
}
```

### OR

```plum
if (true or false) {
    drop "at least one is true"
}
```

### NOT

```plum
if (not false) {
    drop "condition is true"
}
```

## Combined Conditions

Logical operators can be combined with comparisons and parentheses:

```plum
if (age > 18 and ready) {
    drop "allowed"
}
```

```plum
if (age > 18 or has_permission) {
    drop "allowed"
}
```

```plum
if (ready and not done) {
    drop "still working"
}
```

## Implementation

### Lexer

Added tokens:

- `AND`
- `OR`
- `NOT`

### AST

Added:

- `UnaryOperation`

`and` and `or` use the existing `BinaryOperation` node.

### Parser

Added logical expression parsing with precedence:

```text
_expression
    ↓
_or
    ↓
_and
    ↓
_not
    ↓
_comparison
```

### Interpreter

Added evaluation for:

```text
and → left and right
or  → left or right
not → not operand
```
