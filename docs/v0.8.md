# 🍑 Plum v0.8 — If / Else

## Release Date

September 2026

## Overview

Version 0.8 introduces **conditional statements** to Plum using `if` and `else`.

This allows Plum programs to execute different code depending on a condition.

## New Features

### If Statement

```plum
if (condition) {
    statements
}
```

Example:

```plum
if (10 > 5) {
    drop "yes"
}
```

### If / Else Statement

```plum
if (condition) {
    statements
} else {
    statements
}
```

Example:

```plum
if (10 > 5) {
    drop "yes"
} else {
    drop "no"
}
```

### Conditions

Existing comparison operators can be used:

```text
==
!=
>
<
>=
<=
```

Variables and boolean values can also be used as conditions:

```plum
plant int age = (21)

if (age > 18) {
    drop "adult"
} else {
    drop "minor"
}
```

```plum
plant bool ready = (true)

if (ready) {
    drop "ready"
} else {
    drop "not ready"
}
```

### Nested If Statements

`if` statements can be placed inside other `if` blocks.

```plum
if (10 > 5) {
    if (20 > 10) {
        drop "nested yes"
    }
}
```

## Syntax

```text
if_statement → "if" "(" condition ")" "{" statements "}" 
                ("else" "{" statements "}")?
```

## v0.8 Goal

Add basic conditional logic to Plum while keeping existing arithmetic, comparison, boolean, variable, function, and comment functionality working.

## Current Limitations

- No `else if`
- No logical operators
- No loops
